## 启动

Windows 右键 `启动游戏.ps1` → 使用 PowerShell 运行，打开 `http://127.0.0.1:8766/`。启动器使用本机 Codex 自带 Node.js；其他电脑需 Node.js 18 或更新版本。也可在项目目录运行 `node scripts/serve.mjs`，再用浏览器访问该地址。不要双击游戏 index.html，模块加载需要 HTTP 服务。无需账号、API Key 或在线模型。

## 操作

| 操作 | 键位 |
| --- | --- |
| 移动 | A D / ← → |
| 爬梯 | W S / ↑ ↓ |
| 跳跃 | 空格 |
| 冲刺 | Shift / J |
| 互动、交付、登艇 | 按住 E |
| 队友指令 | 1 / 2 / 3，点击场景目标后确认 |
| 暂停／取消 | Esc |

手机横屏使用触控按钮。普通数据节点需两次独立冲刺，Grok 一次可撞开；背包满三块后返艇交付。每次 AI 行动消耗 Token，默认方案不消耗限定词，增加精确约束另耗限定词。补给、证据整理和修复建议可帮助补充 AI Token。第五章先在远端信标集结三人并带齐数据，再分别确认装载、启动六十秒撤离，最后返艇交付和登艇。

“章节挑战”按主线解锁；“章节展示”开放五章供审阅，明确标记展示模式，不写入正式存档与最佳成绩。章间按继续后保存，刷新从本章入口重来。

## 验证与交付

依次运行 `node src/core/verify-core.mjs`、`node scripts/verify-art.mjs`、`node scripts/verify-maps.mjs`、`node scripts/verify-world.mjs`。`node scripts/build-game.mjs` 会先清理再生成 `dist/` 静态部署目录，使用 .js 模块扩展名；随后运行 `node scripts/verify-build.mjs` 检查部署包里的模块、样式和 PNG 美术资产路径。界面固定图形由已生成 PNG 徽章带、面板材质、按钮轨道和环形框承载，动态数字、状态和无障碍文本仍由 HTML/JS 更新。无第三方运行依赖。

主角卡位于 `assets/submission/deepseek-hero-card.png`，实际截图位于 `output/screenshots/`。实施范围、验证证据和限制见 `docs/开发与验收记录.md`。GitHub 源码仓库保持私有，推送到 `main` 后由 GitHub Actions 校验和构建；公开试玩通过 Sites 发布 `dist/`。本地输出和交付压缩包不纳入源码仓库。

## 本轮高清与引导升级

桌面标准模式采用至少 2 倍 Canvas 绘制，手机动态 1.5—2 倍；背景、地图结构、角色、特效独立分层，文字标签和任务界面使用 HTML。首次主流程采用两段、标称八秒且可跳过的出航简报，直接进入可选行为教学；完整互动序章可在档案回看。当前目标随收集、交付、集结与撤离状态更新。

角色动作采用现有姿态配合离散循环、残影、纸页和扫描反馈，尚未新增逐帧手绘图集。本轮自动验证、已交付范围和实屏检查限制见 `docs/高清与首分钟升级验收.md`。2026-10-26 已修复行走混入待机导致的 Grok 武器换边观感，并稳定冲刺、破障姿态，见[人物动作稳定性修复](docs/人物动作稳定性修复-2026-10-26.md)。
