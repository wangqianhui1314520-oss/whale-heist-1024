## 程序如何使用

按 `runtime-catalog.json` 里的实际坐标取样，**不要假定图集格子等宽，也不要按旧清单目标尺寸裁图**。该目录登记的 51 张 PNG 保留生成时的原始尺寸，未做裁切、缩放或拼接后期；缩放发生在运行时。原图 Alpha 检查数据保存在目录中：透明资源确有 Alpha 为 0 的像素，三张 RGB 背景为不透明图。此原图承诺不扩展到目录之外的历史派生框体与预览截图。

坐标均为原图像素坐标 `[x, y, width, height]`：

- `source_rect`：分配给该资源的完整取样区，包括安全留白。
- `content_rect`：区内 Alpha > 8 的内容包围盒，用于普通精灵显示和脚底对齐。
- `solid_rect`：区内 Alpha > 160 的实色包围盒，只供检查主体边缘；不是碰撞盒。

接入适配器位于 [src/render/assets.mjs](../src/render/assets.mjs)。`drawActor` 按角色、状态、方向选姿态，并使用每角色统一的 `native_scale`，避免武器占幅变化造成切姿态时忽大忽小；`drawEffect` 按时间播放四帧效果。普通角色默认用 `content_rect`；特效默认用完整 `source_rect`，以共同中心保持帧间稳定。游戏适配器通过 `fetch` 载入目录，需从项目开发服务器运行；离线图库已使用本地脚本目录，不依赖该请求。

平台的华丽支架属于装饰。站立顶面、实体高度与碰撞盒必须由关卡数据单独定义。墙板和水段未保证无缝平铺；使用前检查接缝。背景按比例适配，人物不要强行拉伸。
