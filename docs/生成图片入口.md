# 生成图片入口

生成图片已经放在项目的 `assets/`，运行时会从这里读取。最方便的入口是：

`assets/preview/index.html`

直接用浏览器打开即可查看离线图库和场景拼装预览。

常用图片：

| 用途 | 文件 |
| --- | --- |
| 主菜单背景 | `assets/backgrounds/menu-background.png` |
| 游戏场景背景 | `assets/backgrounds/gameplay-backdrop.png` |
| 结算背景 | `assets/backgrounds/results-background.png` |
| 视觉目标图 | `assets/concepts/gameplay-sideview-visual-target.png` |
| DeepSeek 主角卡 | `assets/submission/deepseek-hero-card.png` |
| 角色头像 | `assets/portraits/` |
| 角色动作图集 | `assets/atlases/` |
| 破障、诱饵、扫描、冲刺特效 | `assets/fx/` |

当前运行生产包共有 28 张 PNG、96 个 Canvas 可调用采样区；另有 1 张 HUD 图标带 PNG（6 个无文字 CSS 图标）。`assets/prompts/` 和 `assets/provenance/` 保存每张生成图的提示词与来源记录。

视觉实现采用混合方式：背景、角色、机关、特效和面板框体使用生成图片；动态文字、Token、进度、输入框、按钮焦点和无障碍语义继续由 HTML/CSS 提供。这样图片能保持精致，实时信息也不会变成无法更新的死图。
