# 玩家体验升级 · 2026-10-27

本轮围绕首次试玩的可读性、发令节奏、动作容错和重复返程实施升级。此前工作区已有的输入、纸窗进度与后期关卡修复予以保留。玩家体验需要真人验证，本文不把自动化通过等同于玩家满分。

## 已实施

| 玩家遇到的问题 | 当前行为 |
| --- | --- |
| 开场九段对话与三次单选确认较长 | 主流程改为两段出航简报，标称演出八秒，可直接跳过。完整互动序章留在档案，旧存档中的序章可继续恢复。 |
| 未收集就显示交付资料 | 按真实库存、已交付物与机制回执选择下一步；满三格提示回艇，终章逐步提示收集、集结、装载、确认撤离。 |
| 看不清目标所在房间与路线 | 目标标记和可展开的梯路参考。换房目标指向实际可通行出口；事件锁与挑战关闭的出口不进入导航。路线只作走法参考，不承诺无危险。 |
| 发令时反复选取，面板遮挡场景 | 默认选未处理目标；按 1／2／3 后确认按钮获得焦点，Enter 可执行。主体面板精简，复杂编排按需展开。 |
| 三种角色使用相同开路用词 | Grok 为连续／定点破障；Claude 为引开多人／只引一人；GLM 为广域／精准扫描。默认 AI Token ×1，精确 AI Token ×2，限定词或训练额度明确展示。 |
| 扫描风险需要展开才能看到 | 真实预览几何包含警戒器时，确认前直接显示警报提醒。无效操作、取消和重复确认继续不重复扣费。 |
| 两次冲刺等待偏长、梯子对齐较紧 | 当前扩展主线冲刺恢复 2.8→1.65 秒，起跳缓冲 0.14→0.18 秒，离地容错 0.11→0.14 秒，爬梯接入半径 25→30。旧基础地图保持原参数。 |
| 探索后多次原路跑图 | 第二至四章远端资料触发实际返航维护舱，落点在鲸艇附近。捷径不代取资料、不交付、不结算；事件可存档，关闭捷径契约确实封闭。第五章仍须走完整限时路线。 |
| 主角与背景、队友混在一起 | 降低背景亮度与饱和度，按章节调整色调；主角脚下水纹与“你”标记突出位置。 |
| 危险提示排在普通消息后、换章残留旧提示 | 自由行动中的危险消息优先显示；换章清理旧提示与对白计时器。 |

## 源码入口

- `src/game/player-guidance.mjs`：只读行动建议，不推进任务、不扣资源。
- `src/game/world.mjs`、`rooms.mjs`、`contracts.mjs`：动作容错、默认目标、返航维护舱与挑战规则。
- `src/game/story.mjs`、`story-art.mjs`、`src/main.mjs`：短开场、档案入口、消息调度。
- `src/ui/ui-v3.mjs`、`ui.mjs`、`player-polish.css`：动态任务、紧凑指令、费用、风险和键盘焦点。
- `src/render/scene-renderer.mjs`：目标、路线和主角位置反馈，继续使用现有图集。
- `scripts/verify-player-upgrade.mjs`：真实状态驱动、捷径事件、存档、挑战和终章前置条件回归。
